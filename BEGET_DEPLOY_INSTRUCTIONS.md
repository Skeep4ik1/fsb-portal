# Инструкция по загрузке на Beget (cp.beget.com)

Ваш проект скомпилирован в готовую статическую сборку в папке `dist/`.

### Что внутри готовой сборки:
1. `index.html` — главная страница портала
2. `assets/` — стили и скомпилированные скрипты приложения

---

### Пошаговая инструкция по установке на Beget:

#### Шаг 1. Перейдите в панель Beget
1. Откройте [cp.beget.com](https://cp.beget.com/main) и войдите в аккаунт.
2. В меню слева или на главном экране перейдите в раздел **«Файловый менеджер»** (или подключитесь по **FTP/SFTP** через FileZilla).

#### Шаг 2. Откройте папку вашего сайта
1. В файловом менеджере перейдите по пути:
   ```
   имя_домена/public_html
   ```
   *(например, `мойсайт.ru/public_html` или `логин.bget.ru/public_html`)*
2. Если внутри `public_html` есть стандартные файлы-заглушки Beget (например, `index.php`), удалите их или переименуйте.

#### Шаг 3. Загрузите файлы из папки `dist/`
Загрузите в папку `public_html`:
- Файл `index.html`
- Папку `assets` (со всеми файлами внутри)

> **Важно**: в корне `public_html` должен лежать именно `index.html`, а рядом с ним папка `assets`. Не создавайте лишнюю вложенную папку `dist` внутри `public_html`.

#### Шаг 4 (Рекомендуется для SPA). Файл `.htaccess`
Чтобы при переходе по прямым ссылкам или обновлении страниц всё работало корректно, создайте в папке `public_html` файл `.htaccess` со следующим содержимым:

```apache
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  RewriteRule ^index\.html$ - [L]
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule . /index.html [L]
</IfModule>
```

---

После этого ваш портал сразу будет доступен по вашему домену на хостинге Beget!
